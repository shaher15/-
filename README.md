# واصل (Wassel) — إمارة منطقة القصيم
رابط الموقع:https://wasel-qassim.vercel.app 
طبقة ذكاء رقمية تساعد **إمارة منطقة القصيم** على تحسين رحلة المستفيد ومعالجة الطلبات والشكاوى والاقتراحات: فهم احتياج المستفيد، توجيهه للخدمة المناسبة، عرض المتطلبات والتحقق من المرفقات، تحسين الصياغة، دعم الموظف بالتحليل والتلخيص، ومتابعة الحالة بوضوح. واصل **طبقة ذكاء وتكامل فوق الأنظمة الحكومية القائمة** وليس بديلًا عنها. مبني بـ Next.js وTypeScript وTailwind CSS بواجهة عربية (RTL) وخط Tajawal، ويتضمن خيارات سهولة الوصول (نص، صوت، لغة الإشارة السعودية، لقاءات مرئية).

> **بيانات تجريبية:** كل البيانات والأرقام وأرقام المعاملات في النموذج الأولي تجريبية وليست رسمية. الأسماء المنشورة رسميًا والمتحقق منها: "الاستدعاء الإلكتروني" و"الاستعلام عن المعاملة" (alqassim.gov.sa). طبقة التكامل (`lib/integration/emirate-mock-api.ts`) **محاكاة** ولا تتصل بأي نظام حقيقي. التصميم المستهدف: نسخة مستقلة داخل البيئة التقنية المعتمدة لدى الجهة.

> **ملاحظة تقنية:** لا يوجد خادم خلفي منفصل أو قاعدة بيانات؛ التخزين يعتمد على `localStorage` في المتصفح، وبعض التكاملات الخارجية (اتصال مرئي بعيد، تعرّف آلي على لغة الإشارة) لا تزال محلية بانتظار ربطها بمزودات حقيقية. راجع `docs/IMPLEMENTATION_STATUS_AR.md` للتفاصيل الكاملة والدقيقة حول كل ميزة.

## التشغيل محليًا

هذا مشروع **Next.js فقط** (لا يوجد خادم خلفي منفصل) — واجهة الويب ونقاط الـ API (مثل إعادة الصياغة) تعمل جميعًا داخل نفس تطبيق Next.js.

```bash
npm install
npm run dev
```

ثم افتح المتصفح على [http://localhost:3000](http://localhost:3000) — سيتم تحويلك تلقائيًا لصفحة تسجيل الدخول.

للبناء الإنتاجي:

```bash
npm run build
npm run start
```

### إعداد Groq API لإعادة صياغة النصوص

خطوة "إعادة الصياغة" في رحلة تقديم الطلب تستدعي Groq API (نموذج Qwen) عبر مسار خادمي داخلي.

1. أنشئ مفتاح API مجاني من [console.groq.com](https://console.groq.com) (تسجيل حساب ثم إنشاء API Key من لوحة التحكم).
2. انسخ `.env.example` إلى `.env.local`:
   ```bash
   cp .env.example .env.local
   ```
3. ضع مفتاحك في `.env.local`:
   ```
   GROQ_API_KEY=ضع_مفتاحك_هنا
   GROQ_MODEL=qwen/qwen3.6-27b
   ```
   لا تضع المفتاح أبدًا في `.env.example` أو في أي ملف يُرفع للمستودع.
4. أعد تشغيل خادم التطوير (`npm run dev`) بعد تعديل `.env.local`.

### اختبار مسار إعادة الصياغة يدويًا

بعد تشغيل الخادم محليًا:

```bash
curl -X POST http://localhost:3000/api/ai/rewrite-request \
  -H "Content-Type: application/json" \
  -d '{"original_text":"عندي مشكلة تكرر انقطاع المياه في الحي"}'
```

- في حال عدم ضبط `GROQ_API_KEY`، سيعيد المسار الخطأ العربي التالي (وهذا متوقع بدون مفتاح فعلي):
  `{"error":"تعذر إعادة صياغة النص حاليًا. لم يتم تغيير النص الأصلي، ويمكنك المحاولة مرة أخرى."}`
- مع مفتاح صالح، يعيد المسار: `{"original_text": "...", "rewritten_text": "...", "model": "..."}`.

## حسابات الدخول

| الدور | البريد الإلكتروني |
|---|---|
| مستفيد | `beneficiary@example.com` |
| موظف | `employee@example.com` |

تسجيل الدخول عبارة عن اختيار دور من صفحة الحسابات (لا يوجد نظام مصادقة بكلمة مرور بعد)، ويتم حفظ الدور في `localStorage` بالمتصفح.

## المكدس التقني (Stack)

- **Next.js 14** (App Router) + **TypeScript**
- **Tailwind CSS** بألوان هوية حكومية مخصصة (أخضر غامق، نعناعي، رمادي محايد)
- خط **Tajawal** عبر `next/font/google`، واتجاه صفحة **RTL** كامل
- طبقة تجريد ذكاء اصطناعي موحّدة في `lib/ai/provider.ts` (`MockAIProvider`) لجميع الميزات ما عدا إعادة الصياغة
- إعادة صياغة النص عبر Groq API (نموذج Qwen) في `app/api/ai/rewrite-request/route.ts`
- رفع مستندات حقيقي عبر `lib/storage/file-storage-provider.ts` (تخزين محلي عبر Object URL، معزول خلف واجهة قابلة للاستبدال بمخزن سحابي)
- معاينة كاميرا/ميكروفون حقيقية للقاءات المرئية وشرح لغة الإشارة عبر `lib/video/video-provider.ts` (`getUserMedia`)
- بيانات ثابتة في `lib/mock-data/*` وتخزين حالة الجلسة والطلبات عبر `localStorage` (`lib/store/*`)

## أهم الميزات

- رحلة تقديم طلب جديد بخمس خطوات (وصف الاحتياج → نوع الخدمة → إعادة الصياغة → المستندات → المراجعة والإرسال) مع إدخال نصي/صوتي/بلغة الإشارة، إعادة صياغة حقيقية عبر Groq/Qwen، رفع مستندات حقيقي، ومقياس اكتمال تفاعلي.
- تقديم الطلبات بلغة الإشارة عبر معاينة كاميرا حقيقية وتدفق تعرّف ومراجعة.
- **مركز المعرفة الذكي**: متاح كزر عائم في كل صفحات بوابة المستفيد، يفتح كلوحة جانبية دون فقدان حالة الصفحة، مع مصادر قابلة للنقر تعرض تفاصيل كل مصدر.
- بوابة موظف شاملة: مراجعة الطلبات، تصنيف واعتماد/تعديل/رفض اقتراحات الذكاء الاصطناعي بما فيها "الإدارة المقترحة" (لا تُطبَّق تلقائيًا أبدًا)، وتوليد مسودات ردود قابلة للتحرير.
- إحالات الديوان الملكي وديوان المظالم مع حالات تحذير واضحة، والتزام صريح بعدم إصدار أي تفسير قانوني من الذكاء الاصطناعي في قضايا ديوان المظالم.
- إدارة لقاءات مرئية كاملة (طلب، اعتماد وجدولة، غرفة انتظار، معاينة كاميرا/ميكروفون حقيقية، محضر بعد اللقاء).

لمزيد من التفاصيل الدقيقة حول ما هو فعلي مقابل ما لا يزال محليًا بانتظار مزود خارجي، راجع `docs/IMPLEMENTATION_STATUS_AR.md`.
